# Физтех-репетитор — прототип сайта

## Что уже готово
- Регистрация, вход, выход (пароли хранятся в виде хеша, не в открытом виде)
- Уникальный 16-значный ID пользователя (генерируется, но нигде не показывается)
- Автоматическое повышение класса школьника 1 сентября
- Тест на статус репетитора (предмет + класс + квалификация), порог 70%,
  повторная попытка через 24 часа
- Каскад классов: сдал тест на 7–8 класс — можно брать 1–8 класс
- Личный кабинет ученика: класс, контакты, предметы для поиска, объявления
- Личный кабинет репетитора: предметы, достижения, описание, цена, скидка, календарь
- Поиск репетитора по 3 фильтрам (предмет, класс, квалификация) — показываются
  только полные совпадения
- Внутренние сообщения ученик <-> репетитор
- Форум: вопросы с тегами (предмет, класс), ответы, выбор лучшего ответа,
  начисление/списание условной валюты "физтех-баллы", автоматический статус
  репетитора при накоплении 100 баллов по предмету

## Что нужно доделать перед реальным запуском
1. **Банк тестовых вопросов** (`test_bank.py`) — сейчас там всего несколько
   примеров-заглушек. Реальные задания нужно подготовить самостоятельно
   по материалам с phtl.ru, olimpiada.ru, olympmo.ru, distant.pro, os.mipt.ru,
   etudes.ru, kvantik.com, zftsh.online и т.д. — я не переносил их содержимое
   напрямую, так как это защищённые авторским правом материалы конкретных
   ресурсов.
2. **Уведомления по email/push** об объявлениях репетиторам — сейчас
   объявления просто видны репетитору в его кабинете, реальную отправку писем
   нужно подключать отдельно (например, через сервис вроде SendGrid).
3. **Загрузка фото** — сейчас поле photo_url есть в базе, но формы загрузки
   файла ещё нет.
4. Настоящая защита от спама/капча на регистрации.

## Как запустить у себя на компьютере
1. Установи Python 3.11+
2. В папке проекта выполни:
   ```
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```
3. Открой в браузере http://127.0.0.1:8000

## Как выложить на render.com (бесплатно)
1. Создай репозиторий на GitHub и загрузи туда все файлы этой папки
2. Зайди на render.com → New → Web Service → подключи репозиторий
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port 10000`
5. Нажми Create Web Service — через пару минут получишь ссылку вида
   `tutor-site.onrender.com`

По умолчанию используется файл SQLite (`tutor_site.db`) — этого достаточно
для теста, но на Render файловая система непостоянна между деплоями.
Для постоянного хранения данных создай бесплатную базу PostgreSQL
(например, на supabase.com или neon.tech) и добавь в Render переменную
окружения `DATABASE_URL` со строкой подключения — код менять не придётся.
